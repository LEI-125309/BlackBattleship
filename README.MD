# Product Backlog - BlackBattleship (Papergames.io)

Este documento apresenta o Product Backlog do jogo de Batalha Naval online (BlackBattleship), dividido equitativamente pelos 4 membros do grupo para a implementação dos testes de aceitação (Selenium e Selenide).


### Guilherme Cabo: Modos de Jogo e Setup Inicial

* **US01 - Jogar Contra o Robot:** Como jogador, quero escolher a opção "Play vs robot" para poder jogar e treinar sozinho a qualquer hora, sem depender de outros jogadores.
* **US02 - Jogar com um Amigo via Link:** Como jogador, quero gerar um link de convite e partilhá-lo, para que um amigo se possa juntar à minha partida privada sem necessidade de criar conta.
* **US03 - Colocação da Frota:** Como jogador, ao iniciar a partida, quero que os meus 5 navios (tamanhos 5, 4, 3, 3 e 2) sejam posicionados no tabuleiro 10x10, para que o jogo possa começar.
* **US04 - Sistema de Turnos:** Como jogador, quero que o jogo alterne os turnos entre mim e o oponente, para que ambos tenham a mesma oportunidade de disparar.

### Diogo Miranda: Mecânica Central e Feedback

* **US05 - Feedback Visual de Tiro:** Como jogador, quero ver um ícone de fogo quando acerto num navio e um salpico de água quando falho, para perceber o resultado do meu disparo.
* **US06 - Tiro Adicional ao Acertar:** Como jogador, quero poder disparar novamente no mesmo turno sempre que acerto num navio do oponente, para manter a vantagem tática.
* **US07 - Condição de Vitória:** Como jogador, quero que o jogo termine e anuncie o vencedor assim que todos os navios da frota de um dos jogadores forem afundados.
* **US08 - Histórico de Jogadas:** Como jogador, quero consultar um histórico visual dos disparos anteriores (meus e do oponente) para ajustar a minha estratégia.

### Diego Costa: Armas Especiais e Presentes (Gifts)

* **US09 - Aparecimento de Presentes (Gifts):** Como jogador, quero que surjam "presentes" no tabuleiro ao longo da partida, para que possa obter vantagens ao disparar contra eles.
* **US10 - Arma Especial: Míssil Grande:** Como jogador, quero usar o "Míssil Grande" para atingir uma área em cruz (5 quadrados) no tabuleiro do oponente, causando dano numa zona mais ampla.
* **US11 - Arma Especial: Chuva de Mísseis:** Como jogador, quero usar a "Chuva de Mísseis" para efetuar vários disparos aleatórios no tabuleiro do oponente, cobrindo uma área vasta para aumentar a probabilidade de acerto.
* **US12 - Arma Especial: Míssil Nuclear:** Como jogador, quero usar o "Míssil Nuclear" para causar dano massivo numa área alargada (13 quadrados) do tabuleiro, destruindo potenciais navios inimigos.

### Jaime Ferreira: Armas Base, Rankings e Ajuda

* **US13 - Arma Base: Míssil Simples:** Como jogador, quero usar o "Míssil Simples" (1 quadrado de dano, munições ilimitadas) como a minha arma padrão em cada turno.
* **US14 - Consultar Ranking Geral:** Como jogador, quero visualizar o ranking geral dos últimos 30 dias, para comparar a minha pontuação com a de outros jogadores.
* **US15 - Página de Regras:** Como jogador, quero aceder a uma página com as regras completas do jogo, para esclarecer dúvidas sobre a mecânica e o funcionamento das armas.
* **US16 - Página de Estratégias:** Como jogador, quero aceder a uma secção com dicas e táticas (ex: padrões de tiro), para melhorar o meu desempenho no jogo.
